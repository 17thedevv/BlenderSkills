# Strategy evaluation — 2026-10-11

## Local availability and evidence limits

Blender 4.2.0 is available at `D:/tools/blender-4.2.0-windows-x64/blender.exe`. A read-only inspection of the three standard Windows Uninstall registry locations returned no matching Marvelous Designer, CLO, Browzwear, Style3D or Blender install record. `D:/tools` contains the portable Blender folder and prior VRM setup scripts. Earlier scoped inventories likewise found no registered garment specialist. This does not prove that no portable specialist application exists on any drive. No software/asset was installed, purchased or downloaded.

Recovery v2 and the older three panel/drape trials were reviewed before selecting a method. Earlier panel trials welded/bridged pre-shaped surfaces and strongly pinned a yoke. This study uses independently cut planar panels, loose-edge sewing constraints, no yoke plate, sparse neckline anchors and gradual mannequin pose changes. Existing Recovery v2 garment coordinates are used only in a separate comparison scene.

| Approach | Geometry and draping | Artistic control | Agent automation / cost | Rigging / VRM implications | Decision |
|---|---|---|---|---|---|

## Primary sources checked

Blender's [Shape manual](https://docs.blender.org/manual/en/3.4/physics/cloth/settings/shape.html) explains sewing springs made from edges outside faces and warns about unbounded sewing forces. The [4.2 API index](https://docs.blender.org/api/4.2/genindex-S.html) confirms `sewing_force_max`; runtime RNA is authoritative for the installed version. Attempts to fetch the 4.2 Shape/API pages through the web tool returned errors, so the older manual is a concept reference, not proof of current defaults. [ClothSettings API](https://docs.blender.org/api/5.2/bpy.types.ClothSettings.html) likewise documents loose-edge sewing; the experiment uses properties actually present in 4.2. [Cloth on Armature](https://docs.blender.org/manual/en/4.4/physics/cloth/examples.html) supports gradual pose transitions and freezing results, but does not validate this prototype's pose quality.

Marvelous Designer's official [OBJ workflow](https://support.marvelousdesigner.com/hc/en-us/articles/47358223288601-3D-File-OBJ-Import-Export) offers welded/unwelded, thin/thick and pattern/sewing metadata export. These are potential integration options, not evidence that the application is installed or that its API can be automated here.

Two actual prebuilt candidates were checked on creator listing pages: [kimono by adityajaiswal9968](https://sketchfab.com/3d-models/kimono-b430ef733f7b4052aff820ea7864c66d), listed at 14.7k triangles / 7.5k vertices; [Kimono by povchik](https://sketchfab.com/3d-models/kimono-baadb6f960c7431f829bdc0ec5820d9d), creator-described Marvelous Designer training project, 305.2k triangles / 153.6k vertices. Both display Creative Commons Attribution licensing. [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) permits adaptation and commercial redistribution with attribution, a license link and change notice. This is a license-screened **candidate**, not a verified production asset: exact download license/version, author provenance, file contents, separate garment availability, UVs/weights and any third-party rights remain unverified. No assets were downloaded or incorporated; no attribution debt is introduced in this prototype. The lighter candidate is a possible fallback, not a recommendation to use it unseen.

VRM's official [spring-bone documentation](https://vrm.dev/en/vrm1/springbone/) describes a separate secondary bone extension. It does not make Blender's cloth cache portable. Runtime cloth and automatic pose-driven garment corrective morphs are not established by this study.

Selection reasoning: native sewing is the only verified installed strategy that changes both the cut/seam foundation and the source of folds. A small, isolated experiment can test whether its visible benefits justify the solver and real-time integration costs. It is not selected on the promise that the result will be artistically acceptable.
